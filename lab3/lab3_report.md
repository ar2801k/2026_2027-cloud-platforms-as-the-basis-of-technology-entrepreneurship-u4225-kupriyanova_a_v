# Лабораторная работа №3: Исследование Cloud Storage
## Цель работы
Ознакомиться с основными понятиями и принципами работы облачного хранилища Google Cloud Storage, изучить объектную модель хранения данных и базовый функционал сервиса.

## Ход работы

### 1. Создание бакета
Создан бакет `akupriyanova-bucket-lab3` в регионе `europe-west1` (Бельгия) с классом хранения Standard и единым контролем доступа (Uniform).
