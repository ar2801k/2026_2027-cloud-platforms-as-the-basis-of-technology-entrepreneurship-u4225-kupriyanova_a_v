## Ход работы

### 1. Создание Cloud Run сервиса

Был создан сервис `akupriyanova-hello-lab2` из официального дефолтного образа Google:

- **Образ контейнера:** `us-docker.pkg.dev/cloudrun/container/hello`
- **Регион:** `europe-west1` (Бельгия)
- **Аутентификация:** разрешён публичный доступ (Allow public access)
- **Оплата:** Request-based (оплата только за обработку запросов)
- **Минимальное количество экземпляров:** 0 (сервис "засыпает", когда нет запросов)
- **Максимальное количество экземпляров:** 1 (минимальные ресурсы по заданию)

**URL сервиса:** `https://akupriyanova-hello-lab2-307056602443.europe-west1.run.app`

### 2. Тестирование сервиса

После развёртывания сервис стал доступен по указанному URL. При переходе по ссылке отобразилась стандартная страница приветствия "Hello World" от Google Cloud Run.

Страница была обновлена 5–10 раз для генерации тестового трафика. Все запросы обработались успешно, страница открывалась без задержек.

### 3. Анализ логов и метрик

#### Логи (Logs)

В разделе **Observability → Logs** зафиксированы HTTP-запросы, отправленные к сервису:

- Метод: `GET /`
- Код ответа: `200` (успешная обработка)
- Задержка ответа (latency): ~150–300 мс

Каждое обновление страницы в браузере создавало новую запись в логах, что подтверждает корректную работу сервиса.
